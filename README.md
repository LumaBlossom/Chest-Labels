# Chest Labels

A Minecraft mod that allows you to organize your storage by giving chests custom names and icons directly inside the chest interface.

No more guessing what's inside your storage, quickly identify your chests with custom labels and Minecraft item icons!

## Minecraft Fabric License


If you have any issues, PLEASE report them on our GitHub Issues page.

---

# Features

## 🏷Custom Chest Labels

Give your chests unique names directly from the chest GUI.

Labels are saved directly to the chest and remain visible whenever you open it.

---

## 🖼Chest Icons

Assign any Minecraft item as a custom icon for your chest.

Choose from:
- 🪨 Blocks
- ⚔️ Tools
- 🌱 Items
- 💎 Resources
- 🧱 Any item available in Minecraft

Icons make it easy to recognize storage at a glance.

# ⚙️ Customization

### In-Game Editing:
Customize your chest directly from the chest interface:

- Change chest name
- Select a custom icon
- Remove labels
- Update existing storage

No commands or external configuration required.

---

# 📥 Installation

1. Install Forge Loader.
2. Download the Chest Labels mod `.jar` file.
3. Place both files into your `.minecraft/mods` folder.
4. Launch Minecraft and start organizing!

(Optional) Install Mod Menu for additional configuration support.

---

# 🛠️ Configuration

Access customization options directly through the chest GUI.

Configure:
- Custom chest names
- Chest icons
- Label visibility settings
- Storage appearance options
